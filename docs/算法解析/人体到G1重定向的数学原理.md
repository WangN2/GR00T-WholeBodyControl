# 人体到 G1 重定向（Retargeting）的数学原理

> 本文档基于 `gear_sonic/utils/motion_lib/skeleton.py` 与 `gear_sonic/data_process/convert_soma_csv_to_motion_lib.py` 整理，详细说明 SONIC 训练数据中，如何将不同身材人体的运动捕获数据映射到宇树 G1 机器人（29-DOF）的关节空间。

---

## 一、问题定义

### 1.1 为什么需要重定向？

人体骨骼与 G1 机器人在结构上存在本质差异：

| 差异维度 | 人体（SMPL/SOMA） | 宇树 G1 |
|---------|------------------|---------|
| 关节数量 | 24~26 个关节 | 29 个驱动自由度 |
| 关节类型 | 多自由度球关节（3-DOF）为主 | 单自由度铰链（1-DOF）为主 |
| 身体比例 | 因人而异（身高 145~199cm） | 固定机械结构 |
| 躯干结构 | 多段脊柱（颈椎、胸椎、腰椎） | 腰部 3-DOF（yaw/roll/pitch） |
| 手腕 | 人体腕部复杂 | 3-DOF（roll/pitch/yaw） |

**直接复制关节角度不可行**：人的肘关节是 1-DOF，但肩关节是 3-DOF 球关节；G1 的肩部也是 3-DOF，但各轴定义不同。需要一种与骨骼长度无关、只捕获"姿态变化"的映射方法。

### 1.2 核心思想：T-Pose 差分法

> **不直接复制关节角度，而是复制"相对于 T-Pose 的旋转差异"。**

数学上，设源骨骼（人）某关节在时刻 $t$ 的全局旋转为 $R_{src}^t$，其 T-Pose 下的全局旋转为 $R_{src}^{T}$，则**相对旋转差异**为：

$$\Delta R_i = R_{src,i}^t \cdot (R_{src,i}^{T})^{-1}$$

这个 $\Delta R$ 是姿态的本质——它表示"相对于站立姿态，这个关节朝哪个方向转了多少"，与肢体长度无关。

重定向到目标骨骼（G1）时：

$$R_{tgt,i}^t = \Delta R_i \cdot R_{tgt,i}^{T}$$

其中 $R_{tgt,i}^{T}$ 是 G1 对应关节在 T-Pose 下的全局旋转，作为新的基底。

## 二、项目内重定向的六步数学流程

项目中的通用重定向实现在 `SkeletonState.retarget_to()`（`skeleton.py:891-1048`）。虽然 BONES-SEED 的 G1 CSV 已由外部工具（SOMA Retargeter）预重定向，但这段代码展示了完整的数学原理。

### Step 0: 构建 T-Pose 参考状态

```python
source_tpose = SkeletonState.from_rotation_and_root_translation(
    skeleton_tree=self.skeleton_tree,
    r=source_tpose_local_rotation,
    t=source_tpose_root_translation,
    is_local=True,
)
target_tpose = SkeletonState.from_rotation_and_root_translation(
    skeleton_tree=target_skeleton_tree,
    r=target_tpose_local_rotation,
    t=target_tpose_root_translation,
    is_local=True,
)
```

T-Pose 是一个约定的参考姿态（通常双臂平展、身体直立），用于计算"偏移量"。

---

### Step 1: 丢弃无关关节 + 重新估计局部平移

人体有很多 G1 没有的关节（如脊柱多段、手指等）。通过 `joint_mapping` 字典只保留映射中存在的关节。

```python
pairwise_translation = self._get_pairwise_average_translation()
node_names = list(joint_mapping)
new_skeleton_tree = self.skeleton_tree.keep_nodes_by_names(
    node_names, pairwise_translation
)
```

#### 1.1 Pairwise Translation 的计算（skeleton.py:806-816）

当丢弃中间关节时，需要重新估计剩余父子关节之间的局部平移，保证末端关节位置不变。

```python
global_transform_inv = transform_inverse(self.global_transformation)
p1 = global_transform_inv.unsqueeze(-2)
p2 = self.global_transformation.unsqueeze(-3)

pairwise_translation = (
    transform_translation(transform_mul(p1, p2))
    .reshape(-1, len(self.skeleton_tree), len(self.skeleton_tree), 3)
    .mean(axis=0)
)
```

**数学推导**：

全局变换矩阵 $T_i = \begin{bmatrix} R_i & t_i \\ 0 & 1 \end{bmatrix}$（4×4 齐次矩阵）

从关节 $i$ 到关节 $j$ 的相对变换：

$$T_{ij} = T_i^{-1} \cdot T_j$$

取所有时间帧的平均，得到稳定的骨骼长度估计：

$$\bar{t}_{ij} = \frac{1}{N_{frames}} \sum_{f=1}^{F} t_{ij}^{(f)}$$

当删除中间关节 $k$（原链：$i \to k \to j$）时，新的局部平移近似为：

$$t'_{ij} \approx \bar{t}_{ik} + \bar{t}_{kj}$$

代码中通过 `drop_nodes_by_names` 递归累加被删除节点的局部平移来实现。

---

### Step 2: 坐标系对齐（Rotation Alignment）

人体运动捕获数据（BVH）通常使用 Y-up 坐标系，而 G1/MuJoCo 使用 Z-up。需要一个旋转将源骨骼对齐到目标骨骼的朝向。

```python
new_local_rotation = source_tpose.local_rotation.clone()
new_local_rotation[..., 0, :] = quat_mul_norm(
    rotation_to_target_skeleton, source_tpose.local_rotation[..., 0, :]
)

source_tpose = SkeletonState.from_rotation_and_root_translation(
    skeleton_tree=source_tpose.skeleton_tree,
    r=new_local_rotation,
    t=quat_rotate(rotation_to_target_skeleton, source_tpose.root_translation),
    is_local=True,
)
```

**数学表达**：

设坐标系对齐旋转为 $R_{align}$（四元数表示为 $q_{align}$），则：

- 根节点局部旋转：$q'_{root} = q_{align} \otimes q_{root}$
- 根节点平移：$t'_{root} = R_{align} \cdot t_{root}$

其中 $\otimes$ 表示四元数乘法（Hamilton product）。

代码中对**源 T-Pose** 和**源运动状态**都施加同样的对齐旋转，保证相对关系不变。

---

### Step 3: 尺度归一化（Scale Normalization）

人体身高范围 145~199cm，G1 固定约 1.3m。根节点的位移需要按比例缩放。

```python
root_translation_diff = (
    source_state.root_translation - source_tpose.root_translation
) * scale_to_target_skeleton
```

**数学表达**：

$$\Delta t_{scaled} = (t_{motion} - t_{Tpose}) \cdot s$$

其中 $s$ = `scale_to_target_skeleton`。例如：
- 从厘米到米：$s = 0.01$
- 从 1.75m 人体到 1.30m G1：$s \approx 0.74$

**关键细节**：只缩放**根节点的相对位移**（走路的步幅、跳跃的高度），不缩放骨骼链上的局部平移——骨骼长度由目标骨骼的 T-Pose 结构决定。

---

### Step 4: 提取全局旋转差异并重应用（核心步骤）

这是重定向的**灵魂步骤**。

```python
# 目标 T-Pose 的全局旋转作为基底
target_tpose_global_rotation = source_state.global_rotation[0, :].clone()
for current_index, name in enumerate(current_skeleton_tree):
    if name in target_tpose.skeleton_tree:
        target_tpose_global_rotation[current_index, :] = \
            target_tpose.global_rotation[
                target_tpose.skeleton_tree.index(name), :
            ]

# 计算相对旋转差异
global_rotation_diff = quat_mul_norm(
    source_state.global_rotation,
    quat_inverse(source_tpose.global_rotation)
)

# 重应用到目标 T-Pose
new_global_rotation = quat_mul_norm(
    global_rotation_diff, target_tpose_global_rotation
)
```

**分步数学解释**：

#### 4.1 计算源骨骼的全局旋转

通过 Forward Kinematics（FK）从局部旋转递推：

$$R_{global}^{(i)} = R_{global}^{(parent(i))} \cdot R_{local}^{(i)}$$

根节点 $parent(0) = -1$，$R_{global}^{(0)} = R_{local}^{(0)}$。

#### 4.2 相对旋转差异

对源骨骼的每个关节 $i$：

$$\Delta R_i = R_{src,i}^t \otimes (R_{src,i}^{T})^{-1}$$

四元数逆（共轭，对于单位四元数）：

$$q^{-1} = (w, -x, -y, -z) \quad \text{for} \quad q = (w, x, y, z)$$

#### 4.3 重应用到目标 T-Pose

$$R_{tgt,i}^t = \Delta R_i \otimes R_{tgt,i}^{T}$$

**直觉**：如果人抬起了手臂 45°，G1 也抬起对应的手臂 45°——不管两人的上臂长度是否相同。

---

### Step 5: 处理缺失关节（父关节继承）

如果目标骨骼（G1）中有某个关节，但源骨骼（人）中没有对应的映射，则递归向上查找父关节，继承父关节的旋转。

```python
new_global_rotation_output = quat_identity(shape)
for current_index, name in enumerate(target_skeleton_tree):
    while name not in current_skeleton_tree:
        name = target_skeleton_tree.parent_of(name)
    parent_index = current_skeleton_tree.index(name)
    new_global_rotation_output[:, current_index, :] = \
        new_global_rotation[:, parent_index, :]
```

**示例**：G1 的腰部有 `waist_yaw`、`waist_roll`、`waist_pitch` 三个关节。如果人体数据中没有与之精确对应的独立关节，则它们可能都继承自人体"脊柱基部"的旋转。

---

### Step 6: 组装输出并转回局部旋转

```python
source_state = SkeletonState.from_rotation_and_root_translation(
    skeleton_tree=target_skeleton_tree,
    r=new_global_rotation_output,
    t=target_tpose.root_translation + root_translation_diff,
    is_local=False,
).local_repr()
```

- `r=new_global_rotation_output`：使用全局旋转构建新状态
- `t=target_tpose.root_translation + root_translation_diff`：目标 T-Pose 的根位置 + 缩放后的相对位移
- `.local_repr()`：将全局旋转转换回局部旋转

**全局 → 局部旋转转换**：

$$R_{local}^{(i)} = (R_{global}^{(parent(i))})^{-1} \otimes R_{global}^{(i)}$$

根节点 $R_{local}^{(0)} = R_{global}^{(0)}$。

## 三、从四元数到 G1 标量关节角

上述重定向输出的是**全局/局部四元数旋转**。但 G1 的绝大多数关节是**单自由度（1-DOF）铰链关节**——只能绕一个固定轴旋转。

### 3.1 硬编码的 DOF 旋转轴

`convert_soma_csv_to_motion_lib.py:94-127` 定义了每个 DOF 的旋转轴：

```python
DOF_AXIS = np.array([
    [0, 1, 0], [1, 0, 0], [0, 0, 1],   # left hip: yaw, roll, pitch
    [0, 1, 0], [0, 1, 0], [1, 0, 0],   # left leg lower
    [0, 1, 0], [1, 0, 0], [0, 0, 1],   # right hip
    [0, 1, 0], [0, 1, 0], [1, 0, 0],   # right leg lower
    [0, 0, 1], [1, 0, 0], [0, 1, 0],   # waist: yaw, roll, pitch
    [0, 1, 0], [1, 0, 0], [0, 0, 1],   # left shoulder
    [0, 1, 0], [1, 0, 0], [0, 1, 0],   # left arm lower + wrist
    [0, 1, 0], [1, 0, 0], [0, 0, 1],   # right shoulder
    [0, 1, 0], [1, 0, 0], [0, 1, 0],   # right arm lower + wrist
], dtype=np.float32)
```

| 部位 | DOF 数 | 关节 | 旋转轴 |
|------|--------|------|--------|
| 左腿 | 6 | hip_yaw, hip_roll, hip_pitch, knee, ankle_pitch, ankle_roll | y, x, z, y, y, x |
| 右腿 | 6 | （对称） | y, x, z, y, y, x |
| 腰部 | 3 | waist_yaw, waist_roll, waist_pitch | z, x, y |
| 左臂 | 7 | shoulder_pitch, shoulder_roll, shoulder_yaw, elbow, wrist_roll, wrist_pitch, wrist_yaw | y, x, z, y, x, y, z |
| 右臂 | 7 | （对称） | y, x, z, y, x, y, z |

### 3.2 标量角 ↔ 轴角（Axis-Angle）

CSV 中的数据是**标量关节角** $\theta_i$（弧度）。转换为轴角表示：

$$\vec{\omega}_i = \theta_i \cdot \vec{a}_i$$

其中 $\vec{a}_i$ 是 `DOF_AXIS[i]`（单位旋转轴）。

代码实现：

```python
pose_aa = np.zeros((T, NUM_BODIES, 3), dtype=np.float32)
pose_aa[:, 1:NUM_BODIES, :] = DOF_AXIS[None, :, :] * dof[:, :, None]
```

**逆向过程**（从轴角还原标量角）：

$$\theta_i = \vec{\omega}_i \cdot \vec{a}_i = \omega_x a_x + \omega_y a_y + \omega_z a_z$$

如果重定向输出的是多自由度旋转（非纯轴角），则取其沿旋转轴的分量作为标量关节角。这是从球关节到铰链关节的**投影降维**。

## 四、BONES-SEED 数据流的完整处理管线

### 4.1 数据来源与预重定向

BONES-SEED 数据集已经由 **SOMA Retargeter**（基于 NVIDIA Warp 和 Newton 物理引擎）完成了从人体到 G1 的外部预重定向。输出的 CSV 文件包含：

- `root_translate{X,Y,Z}`：根节点位置（厘米）
- `root_rotate{X,Y,Z}`：根节点旋转（欧拉角 xyz，度）
- 29 个关节的标量 DOF（度）

### 4.2 CSV → motion_lib PKL 转换

`convert_soma_csv_to_motion_lib.py` 执行以下数学转换：

```
BONES-SEED CSV (120 fps, 度, 厘米)
    ↓
[单位转换]  度→弧度, 厘米→米
[根旋转]    Euler xyz → 四元数 (xyzw) → wxyz
[降采样]    120 fps → 30 fps (stride-based)
[DOF→轴角]  pose_aa[i] = DOF_AXIS[i] * dof[i]
[根→轴角]   root_rotvec = Rotation.from_quat(root_quat).as_rotvec()
    ↓
motion_lib PKL
```

关键代码：

```python
# 根位置: cm → m
root_pos = np.stack([data["root_translateX"],
                     data["root_translateY"],
                     data["root_translateZ"]], axis=1).astype(np.float32) / 100.0

# 根旋转: Euler xyz(度) → 四元数 xyzw(scipy) → wxyz
root_quat_xyzw = transform.Rotation.from_euler(
    "xyz", euler_deg, degrees=True
).as_quat().astype(np.float32)
root_quat_wxyz = root_quat_xyzw[:, [3, 0, 1, 2]]

# 关节 DOF: 度 → 弧度
joint_pos_mj = np.deg2rad(data[joint_cols].values).astype(np.float32)

# DOF → 轴角
pose_aa[:, 1:NUM_BODIES, :] = DOF_AXIS[None, :, :] * dof[:, :, None]
pose_aa[:, 0, :] = transform.Rotation.from_quat(root_quat_xyzw).as_rotvec()
```

### 4.3 关节顺序映射：IsaacLab ↔ MuJoCo

Isaac Lab 和 MuJoCo 遍历运动学树的顺序不同。G1 的 29 个 DOF 在两个系统中的索引对应关系硬编码为：

```python
MJ_TO_IL = np.array([
    0, 3, 6, 9, 13, 17,    # left leg
    1, 4, 7, 10, 14, 18,   # right leg
    2, 5, 8, 11, 15, 19,   # ...
    21, 23, 25, 27,
    12, 16, 20, 22, 24, 26, 28,
], dtype=np.int32)
```

BONES-SEED CSV 已经是 MuJoCo 顺序，所以训练数据可以直接使用。其他数据源（如 SOMA Retargeter 的 deploy PKL）如果是 IsaacLab 顺序，则通过 `dof_mj = joint_pos[:, MJ_TO_IL]` 重排。

## 六、直觉理解

把重定向想象成"教机器人模仿人的舞蹈"：

| 数学步骤 | 直觉比喻 |
|---------|---------|
| T-Pose | 两人先站成相同的"预备姿势"（双臂平展） |
| 相对旋转差异 | 不看绝对位置，只看"相对于预备姿势，手臂抬起了多少度" |
| 坐标系对齐 | 确保两人面向同一个方向，不会一个朝南一个朝北 |
| 尺度缩放 | 人的步幅大，机器人按比例缩小步幅 |
| 父关节继承 | 人有个"胸椎"关节机器人没有，就用"腰椎"的姿态代替 |
| 1-DOF 投影 | 机器人的肘关节只能前后弯，不能左右扭——把多维旋转压缩到唯一能动的方向 |
